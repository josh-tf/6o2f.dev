Why do some values look wrong?

Screen sizes are in CSS pixels; multiply by the pixel ratio for physical pixels. Browser zoom changes the viewport and the pixel ratio. Some values are rounded or capped on purpose to limit fingerprinting: device memory is rounded and capped, CPU threads may be capped, and connection speed is bucketed. Safari and Firefox do not expose memory or network information at all.
