About the data

The table holds about 380 types from the IANA media type registry and the types browsers, nginx and Apache actually send. Where one extension has several types (for example .ts is both MPEG transport stream and TypeScript) the first listed is the common server default. Text types get ; charset=utf-8 in the copied header. Detection recognises about 70 signatures; text files are checked for valid UTF-8.
