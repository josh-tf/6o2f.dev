Notations

How symbolic mode works

Who: u owner, g group, o others, a all. Operator: + add, - remove, = set exactly. Permissions: r w x, s setuid/setgid, t sticky, X execute only if already executable, or copy another class with u g o. Relative edits like g+w apply to the mode you had when you clicked into the field. With no who, this tool means a; real chmod would apply your umask.
