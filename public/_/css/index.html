    What is changed and what isn't
    • Strings, url() contents and custom property values (--x: …) are copied exactly.
    • Minify drops comments except /*! licence */ ones, collapses whitespace and removes the last semicolon in each block unless you keep it.
    • Sorting reorders runs of declarations alphabetically, vendor-prefixed versions first, custom properties on top. It never moves anything past a comment or nested rule, and warns where a longhand precedes its shorthand, because sorting would change which one wins.
    • The gzip figure is measured with your browser's own gzip, so it is close to what a server sends.
