JSON to types

Paste sample JSON and get TypeScript, JSON Schema, Python or Go types. Array items are merged, so keys missing from some items become optional. Runs in your browser; nothing is sent.

Options

How types are worked out
  • Every value found at the same place is merged: all items of an array, and all objects under the same key. A key that isn't in every object is optional (?, NotRequired, a pointer with omitempty, or left out of required).
  • Different value types become a union (string | null); Go has no unions, so mixed values become any.
  • Object types are named after their key in PascalCase; array items get the singular (categories → Category). Objects with the same structure share one type; a name clash gets the parent's name as a prefix.
  • With date detection on, strings that are all ISO 8601 dates are marked (format: date-time in JSON Schema, time.Time in Go, a comment elsewhere).
  • Whole numbers are integer / int / int64 unless any sample has a fraction. A sample can only show what it contains: check optional fields and unions against your real data.
