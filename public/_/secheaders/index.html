How grading works

Scoring

The score starts at 100. Failed checks cost more than warnings; informational checks cost nothing. A page that is not served over HTTPS is always F. A+ needs 95 or more with no failed checks; then A from 85, B from 70, C from 55, D from 40.

We fetch the page with a GET from our server (redirects followed, first 256 KB), and separately request the http:// version to see whether it redirects to HTTPS. Headers your server only sends to logged-in users or specific browsers will not be seen.
