Unescape

    What each target escapes
    • JSON: " \ and control characters, plus the line separators U+2028 and U+2029 as \u2028 and \u2029, so the result is also valid JavaScript.
    • JavaScript: both quote kinds, so it works inside '…' or "…". Unescape understands \x, \u, \u{…}, legacy octal and line continuations.
    • Python: \x, \u, \U, octal. Unknown escapes such as \d are kept as written, as Python does.
    • C: control characters become 3-digit octal, because \x would swallow following hex digits. Non-ASCII becomes UTF-8 bytes.
    • Shell: single quotes are literal; a ' becomes '\''. In double quotes \ " $ ` are escaped; interactive bash may still expand !.
    • Regex: every metacharacter plus /; - becomes \x2d. Safe in a literal or a character class, with or without the u flag, and in PCRE, Python and Java.
    • CSV: quoted only when needed, with inner quotes doubled (RFC 4180).
    • URL: like encodeURIComponent, plus ! ' ( ) * (RFC 3986). Unescape treats + as a space.
