Labyrinth

Bots caught by the honeypots, and everything the maze feeds them.

How it works

IPs that hit a honeypot (scanner paths on any host, or a hidden link robots.txt forbids) get 24 hours in an endless, slow fake labyrinth: pages, directory listings, JSON and bait files that only lead deeper. Signed-in users always get through. Edge blocks are in Cloudflare security events.

The live map runs about 8 seconds behind. Only each IP's first 50 requests a day are logged, so a long crawl stops moving on the map while its counters keep going.
