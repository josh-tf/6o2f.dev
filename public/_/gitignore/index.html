Tips
  • Already committed a file? Ignoring it is not enough: run git rm --cached <file>.
  • Lines starting with ! re-include something an earlier pattern ignored.
  • Editor and OS files are often better in your global ignore file: git config --global core.excludesFile ~/.gitignore_global.
  • The selection is kept in the page address, so you can bookmark or share it.
