TOTP

One-time codes from a base32 secret (RFC 6238 and RFC 4226). Runs in your browser.

Secret

The sample secret is public, so its codes protect nothing. Spaces, hyphens and lowercase are fine.

The secret never leaves this page. By default it is kept in memory only and is gone when you close or reload the tab. If you tick "Remember", it is saved unencrypted in this browser's local storage, so do not tick it on a shared computer.

About these codes

A code is HMAC(secret, counter) cut down to 6 to 8 digits. TOTP uses counter = floor(unix time / period), so the code changes every period and your device clock must be accurate. HOTP uses an explicit counter that you advance by hand. Most services use SHA-1, 6 digits, 30 seconds, and many authenticator apps ignore other settings.
