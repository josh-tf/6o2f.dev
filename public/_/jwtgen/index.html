JWT signer

Build and sign a JSON Web Token with HS256/384/512, RS256 or ES256, then verify it. Runs in your browser; keys and secrets are never sent. To inspect an existing token use the JWT decoder.

    Notes
    • HS* secrets should be at least as long as the hash (32, 48 or 64 bytes); shorter ones work but are easier to brute-force.
    • Times (iat, exp, nbf) are seconds since 1970 UTC.
    • The decoder link does not carry the token: paste it there yourself.
    • Generated throwaway keys exist only in this tab.
