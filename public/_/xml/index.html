    How XML maps to JSON

      

    • Attributes become "@name"; text next to attributes or child elements becomes "#text".
      • 

    • An element with only text becomes a string; an empty element becomes "".
      • 

    • Repeated child elements become an array. Names keep their prefix (dc:title), and xmlns attributes stay as "@xmlns:dc", so namespaces survive the round trip.
      • 

    • CDATA either merges into the text or stays as "#cdata"; with Keep comments on, comments become "#comment".
      • 

    • JSON → XML reverses this. Keys that aren't valid XML names are repaired and listed as warnings.
