Key pairs

Generate RSA, ECDSA and Ed25519 key pairs with WebCrypto. Export PEM, JWK and OpenSSH formats.

Keys are generated in this browser and never sent or stored. Reloading the page discards them, so copy or download what you need first.

Using these keys
  • Append the OpenSSH line to ~/.ssh/authorized_keys on a server.
  • Save the private key as e.g. id_ecdsa with chmod 600. OpenSSH reads PKCS#8 RSA and ECDSA keys directly; convert Ed25519 keys with ssh-keygen -p -f id_ed25519 if your OpenSSH version rejects them.
  • Check a fingerprint with ssh-keygen -lf key.pub.
  • JWKs plug into JWT libraries: see the JWT signer.
