Roman numerals

    How the rules work

    Letters add up (VI = 6) unless a smaller one sits before a larger one, which subtracts (IV = 4). Only I, X and C subtract, and only from the next two letters up: IV IX XL XC CD CM. No letter repeats more than three times, and V, L, D never repeat. Standard numerals end at 3999; beyond that a bar over a letter (vinculum) multiplies it by 1000, so 5000 is V̅.
