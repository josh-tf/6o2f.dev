What the dialect changes

Only identifier quoting. PostgreSQL and SQLite output "name", MySQL outputs `name`; Generic keeps quotes as written. MySQL also reads "…" and # as strings and comments and allows backslash escapes; PostgreSQL reads [ ] as array brackets. $$dollar quotes$$ and E'…' strings work everywhere. Minify keeps optimiser hints (/*+ … */, /*! … */).
