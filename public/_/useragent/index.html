    How reliable is a user agent?

    Not very. Anyone can send any string, every browser pretends to be "Mozilla" and "Safari", and Chromium now freezes the OS and minor version (the "reduced" UA). Use it for statistics and bot triage, never for security. For features, test the feature itself. Bot names here come from a hand-made table of about 80 crawlers and HTTP clients; real crawlers should be verified by reverse DNS.
